## pytorch常见API

PyTorch 是深度学习领域非常流行的框架，常见 API 涵盖张量操作、神经网络构建、自动求导、数据加载 and 优化等方面。以下是分类汇总及常用 API 简介：

**一、张量(Tensor)相关**

- `torch.tensor()`：创建张量
- `torch.zeros()` / `torch.ones()` / `torch.randn()`：初始化特定内容的张量
- `tensor.view()` / `tensor.reshape()`：张量形状变换
- `torch.cat()` / `torch.stack()`：拼接、堆叠
- `tensor.cuda()` / `tensor.cpu()`：设备转移
- `tensor.numpy()`：转换为 NumPy 数组

**二、数学与逻辑运算**

- `torch.add()` / `torch.sub()` / `torch.mul()` / `torch.div()`：基础四则运算
- `torch.mean()计算张量（Tensor）均值` / `torch.sum()` / `torch.max()` / `torch.min()`
- `torch.clamp()`：裁剪

**三、自动求导(Autograd)**

- `tensor.requires_grad_()`：设置是否追踪梯度
- `torch.autograd.grad()`：计算梯度
- `tensor.backward()`：反向传播

**四、神经网络模块 (nn)**

- `nn.Module`：神经网络基类
- `nn.Linear`：全连接层
- `nn.Conv2d`：二维卷积层
- `nn.ReLU` / `nn.Sigmoid` / `nn.Tanh`：激活函数
- `nn.Sequential`：顺序搭建模型
- `nn.CrossEntropyLoss` / `nn.MSELoss`：常用损失函数

**五、模型训练相关**

- `optim.SGD` / `optim.Adam`：优化器
- `optimizer.zero_grad()` / `optimizer.step()`
- `model.train()` / `model.eval()`

**六、数据处理**

- `torch.utils.data.DataLoader`：数据加载
- `torch.utils.data.Dataset`：自定义数据集

**七、常见用法补充**

- `torch.save()` / `torch.load()`：模型保存、加载
- `torch.no_grad()`：关闭自动梯度追踪（如推理场景）

`torch.normal()` 是 PyTorch 中用于生成服从正态分布（高斯分布，Normal Distribution）随机数的函数。常常用于初始化权重、生成噪声、仿真实验等。

`torch.matmul()` 是 PyTorch 中用于张量（Tensor）乘法的通用函数，支持多维高维张量运算。其行为根据输入的张量维度自动适应，广泛用于深度学习中的矩阵计算、线性变换。

**API定义**

```
python
torch.matmul(input, other, *, out=None)
```

- `input`：第一个待相乘的张量
- `other`：第二个待相乘的张量
- `out`（可选）：输出目标张量

**功能&适配多种场景**

- 一维 1D1*D* × 一维：返回向量点积（标量）
- 二维 2D2*D* × 二维：返回普遍的矩阵乘法
- 一维 × 二维：视为 1×n1×*n* 行向量乘二维矩阵
- 二维 × 一维：视为二维矩阵乘 n×1*n*×1 列向量，返回一维结果
- 高维（Batch）：自动采用广播，比 `mm` 更灵活
- 支持不同batch维度下的批量矩阵乘法（非常适用于神经网络中的大规模数据）

## 014 数值稳定性、初始化、激活函数

- **根因**：反向传播是矩阵连乘 $\prod_k W^{(k)}\,\mathrm{diag}(\phi'(z^{(k-1)}))$。连乘项尺度 **>1 → 梯度爆炸**（NaN/溢出），**<1 → 梯度消失**（浅层不更新）。
- **三大对策**：① 梯度裁剪（按范数缩小，治爆炸）；② 控制每层方差不漂移；③ 合理随机初始化。
- **不能全 0 初始化**：同层神经元前向输出相同、反向梯度相同 → 永远同步更新 → 退化为单神经元（**对称性无法打破**）。
- **初始化选择**（必记配对）：
  | 方法 | 方差 | 适用激活 |
  |---|---|---|
  | **Xavier** | $\mathrm{Var}(w)=\frac{2}{n_{in}+n_{out}}$ | Sigmoid / Tanh（原点附近近似线性）|
  | **He / Kaiming** | $\mathrm{Var}(w)=\frac{2}{n_{in}}$ | ReLU（补偿负半轴清零的一半方差）|
- **激活函数**：Sigmoid 导数最大仅 **0.25**（易消失、非零中心）；Tanh 零中心但仍饱和；ReLU 正半轴导数恒 1（缓解消失）但负半轴为 0（**Dead ReLU**）。
- **关键区分**：初始化是**训练前**静态控制方差，BN 是**训练中**动态归一化，二者互补。

## 015 / 018 Kaggle 房价预测（回归实战）

- **为何用 log 目标**：房价关心**相对误差**，`log(SalePrice)` 把右偏长尾压平，等价于优化相对误差。评估用 **log RMSE**。

- **实战经验**：小样本（1460 条）→ 用 **K 折交叉验证** 降低单次切分偏差；MLP 要**小网络 + Dropout(0.05) + early stopping**；用 Adam + `weight_decay` 时注意**别把 bias 一起衰减**（会破坏 log 均值基线，Ridge 闭式解反而更稳）。

## 019 卷积层（从 MLP 推导）

- **一句话**：卷积 = 在全连接上施加**平移不变性**（权重与输出位置无关 → 权重共享）+ **局部性**（只看 $\pm\Delta$ 邻域）两条先验后的特殊形式 → "**weight-shared 的稀疏全连接**"。
- **参数解耦**：参数量只与核大小 $(2\Delta+1)^2$ 有关，**与输入尺寸无关**（CNN 相比 MLP 的核心优势）。
- **互相关 vs 卷积**：框架 `Conv2d` 实际做**互相关**（核不翻转）；数学卷积要翻转核 180°。因核是学出来的，翻不翻转等效，术语沿用"卷积"。
- **输出尺寸**（无填充步幅）：$(n_h-k_h+1)\times(n_w-k_w+1)$。
- **直觉**：核遇到相似模式 → 响应大；浅层学边缘/纹理，深层组合出语义。
- **易错**：`Conv2d` 要求 **4D 输入** `(B,C,H,W)`，单图需 `reshape((1,1,H,W))`。

## 020 填充与步幅

- **填充 Padding（针对小输入）**：四周补 0 保留边缘、控制输出大小。若要**输出=输入**需 $p=k-1$。
- **奇数核的原因**：$k$ 奇 → $p=k-1$ 偶 → 可上下/左右**对称**各填 $(k-1)/2$；偶数核则不对称。故主流用 $3\times3$、$5\times5$、$7\times7$。
- **步幅 Stride（针对大输入）**：每次跳 $s$ 像素，成倍下采样；$s=2$ 输出边长约减半，一般 $s\in\{1,2\}$。
- **统一公式**（必记）：
  $$\text{输出}=\left\lfloor \frac{n+p-k}{s}\right\rfloor+1 \quad(\text{特例 }p=k-1,\ s=1\Rightarrow\text{输出}=\text{输入})$$
- **PyTorch 坑**：`padding` 参数是**单侧**值，公式里 $p$ 通常指**总填充** = 2×padding。

## 021 多输入多输出通道

- **多输入通道**（$c_i>1$）：核形状 $(c_i,k_h,k_w)$，**核通道数 = 输入通道数**；每通道分别卷积再**逐元素相加** → 输出仍是**单**特征图。
- **多输出通道**（$c_o>1$）：核形状 $(c_o,c_i,k_h,k_w)$（**4D**），每个输出通道 = 一个独立 3D 核 = 一个模式检测器。
- **$1\times1$ 卷积**：不混合空间，只在**通道维做全连接** → 等价矩阵乘 $Y_{c_o\times hw}=K_{c_o\times c_i}\cdot X_{c_i\times hw}$。用途：通道升/降维、跨通道融合、接 ReLU 加非线性。
- **参数量**：$c_o\cdot c_i\cdot k_h\cdot k_w + c_o$，**与空间尺寸无关**。
- **实战（ResNet Bottleneck）**：1×1 降维(256→64) → 3×3 提特征 → 1×1 升维(64→256)，参数量比直接 3×3 省约 **8.5 倍**。
- **接 BN 时** `Conv2d` 设 `bias=False`（BN 自带偏移，bias 无意义）。
- **易混**：核的**内层维 = 输入** $c_i$，**外层维 = 输出** $c_o$；`nn.Conv2d` 参数顺序是**先 in 后 out**。

## 022 池化层

- **作用**：① 缓解卷积对**位置过度敏感**（平移/像素偏移容忍）；② 降维减算量。
- **三大特性**（与卷积的关键区别）：**无可学习参数**、**通道独立**（不融合通道，**输出通道数=输入通道数**）。
- **Max vs Avg**：MaxPool 取最显著特征，工程**默认首选**；AvgPool 更平滑，多用于网络末端（全局池化）。
- **PyTorch 坑**：`MaxPool2d`/`AvgPool2d` 的 `stride` **默认 = kernel_size**（不是 1！），与 `Conv2d`（默认 1）不同。
- **经典配置**：`kernel_size=2, stride=2` → 宽高减半、算量降到 1/4。
- **"除法性质"**：经典配置（$p=0,\ s=k$）下，输出 = **输入 ÷ 窗口大小**（如 28/2=14）。
- **现代趋势**：GAP（`nn.AdaptiveAvgPool2d((1,1))`）替代全连接头；或用 stride=2 卷积替代池化（可学习下采样）。

## 023 经典神经网络 LeNet（CNN 范式奠基）

- **历史地位**：第一个成功的 CNN（LeCun 1998，手写数字识别），确立 **卷积→池化→…→全连接→输出** 范式，后续 AlexNet/VGG/ResNet 之祖。
- **结构形状演变**（输入 `(1,1,28,28)`）：
  $$28\xrightarrow{\text{Conv k5 p2}}28\xrightarrow{\text{Pool}}14\xrightarrow{\text{Conv k5}}10\xrightarrow{\text{Pool}}5\xrightarrow{\text{Flatten}}400\to120\to84\to10$$
  通道：$1\to6\to16$。体现 CNN **"空间压缩 + 通道扩展"** 的金字塔运动（像素 → 语义）。
- **参数量真相**：全连接层占 **96%**（≈59k / 总 ≈61.7k），卷积只占 4% → 这是后续网络"减全连接、加深卷积"的动机。
- **古今对照**：原版 Sigmoid + AvgPool + 5×5 核；现代换 **ReLU + MaxPool + 3×3 核**（更快更准）。
- **训练要点**：Xavier 初始化（`net.apply(init_weights)`）；Sigmoid 梯度小 → **lr 要大（0.9）**，换 ReLU 后降到 0.01~0.1；推理前务必 `net.eval()`。
- **调试黄金法则**：网络写好后**先用随机张量过一遍逐层打印 `X.shape`**，比训练后报错再查省时间。
- **CNN 三大不变原则**：**局部连接**、**权值共享**、**分层抽象**——至今未变。

- **Q1：卷积与池化层的默认步幅（`stride`）如何界定？是否有必要手动设置 `stride = 1`？**
  - **解析**：无必要手动设置。卷积层（`nn.Conv2d`）默认 `stride = 1`，旨在逐像素滑动、重叠提取像素间过渡特征；而池化层（`nn.AvgPool2d` / `nn.MaxPool2d`）默认 `stride = kernel_size`（无重叠滑动），其哲学是为了进行特征的空间降维与聚合。
- **Q2：多通道卷积输出（如 6 个输出通道）如何避免学到一模一样的重复冗余特征？**
  - **解析**：核心在于**对称性破缺（Symmetry Breaking）**。训练前卷积核权重采用**随机初始化（如 Xavier）**，使各通道具有不同的初始观测起点；在前向和反向传播中，由于起点不同导致它们接收到的梯度更新方向不同，最终自然分化为提取不同边缘或纹理特征的提取器。若初始化权重完全一致，则会陷入对称性陷阱无法分化。
- **Q3：如何精确界定并计算 `Conv2d` 和 `AvgPool2d` 的输出形状规则？池化层是否具有“除法性质”？**
  - **Conv2d 形状规则**：
    $$\text{Output} = \lfloor \frac{\text{Input} - \text{Kernel} + 2 \times \text{Padding}}{\text{Stride}} \rfloor + 1$$
    *直观设计法*：若 `stride=1`，令 `padding = (kernel_size - 1) / 2`，则输出尺寸与输入完全一致。例如 `kernel_size=5, padding=2`，输入为 $28 \times 28$ 时，其输出尺寸依然是 $28 \times 28$（完美抵消缩小效应）。
  - **AvgPool2d / MaxPool2d 形状规则与“除法性质”**：
    $$\text{Output} = \lfloor \frac{\text{Input} - \text{Kernel} + 2 \times \text{Padding}}{\text{Stride}} \rfloor + 1$$
    *“除法性质”的数学证明*：在绝大多数神经网络设计中，池化层通常满足：① 不做边缘填充 $Padding = 0$；② 步幅等于窗口大小 $Stride = Kernel$。
    将这两点代入公式可得：$\text{Output} = \lfloor \frac{\text{Input} - Kernel}{Kernel} \rfloor + 1 = \lfloor \frac{\text{Input}}{Kernel} - 1 \rfloor + 1 = \lfloor \frac{\text{Input}}{Kernel} \rfloor$。
    因此，池化层在经典配置下输出尺寸非常简单地等于 **“输入尺寸直接除以池化窗口大小”**。例如，输入为 $28 \times 28$，池化核大小为 2，默认步幅为 2，输出尺寸就是 $\frac{28}{2} = 14$，即 $14 \times 14$。这就是池化层标志性的**等比例“除法性质”**。
- **Q4：以 6 个 $5 \times 5$ 卷积核扫描 $32 \times 32$ 单通道输入，最终输出维度是 $6 \times 28 \times 28$ 吗？如何直观理解其空间流动？**
  - **解析**：是的。根据 Conv2d 形状规则：$\text{Output} = \frac{32 - 5 + 2 \times 0}{1} + 1 = 28$。在三维流动中，每个卷积核都是一个独立的 3D 滤波器（此处深度与输入通道数 1 相同），6 个卷积核独立滑动，各自生成一个 $28 \times 28$ 的 2D 特征图（代表提取的不同特征），最终在通道维度拼接形成形状为 $(6, 28, 28)$ 的 3D 张量。
- **Q5：什么是线性运算？如何分辨哪些层需要激活函数？非线性层不需要加激活吗？**
  - **解析**：
    - **线性运算判定**：卷积（`Conv2d`）和全连接（`Linear`）在数学上满足可加性与齐次性，仅是输入权重的加权求和，属于纯线性操作。
    - **打破线性的意义**：没有激活函数时，多层线性嵌套在数学上会合并退化为单层线性（即 $W_2(W_1x + b_1) + b_2 = W'x + b'$），令“深度”失去价值；非线性激活函数（如 `ReLU` / `Sigmoid`）相当于折叠和弯曲特征空间，将复杂的线性不可分数据（如 XOR 异或问题）映射到线性可分的决策新空间。
    - **非线性层免激活**：最大池化 `MaxPool2d`、`ReLU` 等本身已具有非线性特性，因此其后绝不需要多余的激活函数，激活函数仅紧跟在卷积或全连接等线性运算后。

## 024 深度卷积神经网络 AlexNet（深度学习的"起点"）

- **历史地位**：2012 ImageNet 夺冠，宣告"**专家手工提特征**"时代终结 → CNN **端到端**自动学特征，最后一层把学到的表示喂给 softmax 回归。
- **崛起的两个前提**（必记）：**大数据**（ImageNet 2010，百万级）+ **算力**（GPU）。模型一直在，是数据和算力到位才点燃。
- **相比 LeNet 的五大改动**：① 更深（**5 卷积 + 3 全连接**）；② **ReLU** 替代 Sigmoid（缓解梯度消失）；③ **MaxPool** 替代 AvgPool；④ 首次大规模 **Dropout(0.5)**（全连接层防过拟合）；⑤ **数据增强**（翻转/裁剪/颜色）。
- **结构演变**（输入 `1×224×224`）：
  $$224\xrightarrow{\text{Conv k11 s4}}54\xrightarrow{\text{Pool}}26\xrightarrow{\text{Conv k5 p2}}26\xrightarrow{\text{Pool}}12\xrightarrow{\text{3×Conv k3}}12\xrightarrow{\text{Pool}}5\to\text{FC }4096\to4096\to10$$
  通道：$1\to96\to256\to384\to256$。
- **关键洞察**（贯穿后续所有网络）：**参数量主要在全连接层，计算量主要在卷积层**——这正是 NiN/GoogLeNet 后来"砍全连接"的动机。
- **训练**：lr=0.01，epochs=10 → test acc ≈ 0.88。

## 025 使用块的网络 VGG（结构规整化）

- **解决的问题**：AlexNet 结构**不规则、设计思想难复用**。VGG 提出"**块（block）**"思想——把网络拆成可重复堆叠的标准单元。
- **VGG 块**：`[Conv(3×3, p=1) + ReLU] × n → MaxPool(2, s=2)`。`p=1` 配 `3×3` → **卷积不改高宽**，把"提特征"和"降采样"**职责分离**（卷积只管特征，池化只管减半）。
- **全 3×3 的理由**（必记）：两个 `3×3` 堆叠 = 一个 `5×5` 的感受野，但**参数更少**（$2\times9=18$ vs $25$）且**非线性更强**（多过一次 ReLU）→ 证明 **"深而窄" 优于 "浅而宽"**。
- **经典递进规律**：每过一个块 **高宽减半、通道翻倍**（如 $64\to128\to256\to512$），空间信息换成通道（语义）信息。
- **可参数化**：用 `conv_arch=((1,64),(1,128),(2,256),(2,512),(2,512))` 描述 VGG-11；改这个元组即可缩放网络。实战为加速训练用 `ratio=4` 把所有通道整除变窄。
- **训练**：lr=0.05，epochs=10，bs=128 → test acc ≈ 0.92。

## 026 网络中的网络 NiN（用 1×1 卷积砍掉全连接）

- **核心武器 1 — NiN 块**：`Conv(k×k) → Conv(1×1) → Conv(1×1)`（各跟 ReLU）。两个 `1×1` 相当于在**每个像素位置上套一个小型 MLP**（"Network in Network"），增强通道间的非线性组合。
- **核心武器 2 — 全局平均池化 GAP**（`nn.AdaptiveAvgPool2d((1,1))`）：用"每个通道求一个均值"替代庞大的全连接头。让**输出通道数 = 类别数**，GAP 后直接得到分类分数向量，**几乎零参数**。
- **GAP 两大优势**（你的笔记）：① **抑制过拟合**——直接平均空间信息、不保留待拟合的空间细节；② **输入尺寸灵活**——输出只与通道数相关，网络可吃任意分辨率。
- **全连接层三宗罪**（被 GAP 替代的原因）：**参数爆炸、易过拟合、输入尺寸被锁死**。
- **踩坑（重要）**：**权重初始化决定成败**——必须 `kaiming_normal_(mode='fan_out', nonlinearity='relu')`；用默认初始化会让 loss 卡在 $\ln 10\approx2.3$（等于随机瞎猜）。且**换初始化必须重调 lr**，否则对照不公平（初始化与学习率**耦合**）。
- **收敛慢**：NiN 参数少 → 需更多轮次。1 轮 acc≈0.1（随机），20 轮才 ≈0.89。
- **训练**：lr=0.05，epochs=20，bs=128 → test acc ≈ 0.89。

## 027 含并行连结的网络 GoogLeNet（多尺度并行）

- **核心思想**：不再纠结"该用多大的卷积核"——**Inception 块**把 `1×1 / 3×3 / 5×5 / MaxPool` **四条路并行**跑，最后在**通道维拼接**，让网络自己学各路的权重。
- **Inception 块四条路**（四条路高宽都不变，靠 padding 保证）：
  | 路 | 结构 | 作用 |
  |---|---|---|
  | 1 | `Conv1×1` | 抽**通道**信息 |
  | 2 | `Conv1×1 → Conv3×3 p1` | 中等空间特征 |
  | 3 | `Conv1×1 → Conv5×5 p2` | 大范围空间特征 |
  | 4 | `MaxPool3×3 p1 → Conv1×1` | 池化分支 |
- **1×1 瓶颈降维**：在昂贵的 `3×3/5×5` **之前**先用 `1×1` 压通道，大幅省算力（先降维再提特征）。
- **结构**（输入降到 `96×96` 加速）：`b1`(7×7s2)→`b2`→`b3`(2×Inception)→`b4`(5×Inception)→`b5`(2×Inception)→**GAP**→FC(1024→10)。首个**超 100 层卷积**的网络，参数却只 ~5M（继承 NiN 的 GAP）。
- **参数直觉**：`5×5`(25C²) 最贵 → 用两个 `3×3` 替代（V3 的演进），甚至**非对称卷积** `1×7 / 7×1` 进一步减参。
- **踩坑**：同样的**初始化 + lr 耦合**——lr=0.1 会让 loss 爆到 9.24，降到 0.05 才正常。
- **训练**：lr=0.05，epochs=15，bs=256 → test acc ≈ 0.89。

## 028 批量归一化 BatchNorm（让超深网络可训练）

- **要解决的问题**：**内部协变量偏移（ICS）**——前层参数一更新，后层输入分布就漂移，逐层放大。后果：Sigmoid 漂进**饱和区**（导数→0 梯度消失）；ReLU 失去有效非线性。
- **两步走**（必记公式）：
  $$\hat{x}=\frac{x-\mu_B}{\sqrt{\sigma_B^2+\epsilon}}\quad(\text{标准化为 0 均值 1 方差})\qquad y=\gamma\hat{x}+\beta\quad(\text{可学习缩放平移，恢复表达力})$$
- **训练 vs 推理**（核心区别）：
  - **训练**：用**当前 batch** 的 $\mu_B,\sigma_B^2$；同时用动量累积全局 `moving_mean / moving_var`。
  - **推理**：用累积好的**全局统计量**（推理可能只来一张图，算不出可靠的 batch 统计）。
- **作用维度**：**全连接** 沿 `dim=0`（样本维）；**卷积** 沿 `dim=(0,2,3)`（样本+空间，**保留通道维**）——即"每像素当样本、每通道当特征"。
- **$\gamma,\beta$ 怎么更新的？**（你的答疑重点）：代码里**看不到** `gamma = ...` 赋值。它们注册为 `nn.Parameter` → forward 里 `Y=γ·X̂+β` 把它们**挂进计算图** → `loss.backward()` 填 `.grad` → 真正的赋值在 **`optimizer.step()` 内部**完成。`X_hat` 是 $\gamma,\beta$ 接入计算图的入口。
- **BN vs 权重衰退**（易混）：权重衰退作用在**参数 $w$** 上（惩罚大权重、控复杂度、防过拟合）；BN 作用在**激活值**上（稳分布、加速收敛、可用更大 lr）。二者不冲突常并用；但 BN 会抹掉整体尺度，对其前一层做 weight decay 意义削弱。
- **收益**：BN 允许**更大学习率**（实验 lr=1.0），收敛显著加快。学到的 $\gamma$ 从全 1 分化成各不相同（如 `[3.38, 2.44, …]`）。

## 029 残差神经网络 ResNet（残差连接，可训练千层）

- **要解决的问题**：**加层不一定更好**——更深的模型族若不包含浅模型，反而可能更差。ResNet 用 **shortcut** 让新模型族**嵌套包含**旧模型族：学不到东西时退化为恒等，**至少不变差**。
- **残差块**：$f(x)=g(x)+x$，其中主路径 $g(x)=$ `Conv3×3→BN→ReLU→Conv3×3→BN`，相加后再过 ReLU。
  - 当 $g(x)=0$ → $f(x)=x$（**恒等映射**）；理解为 $x$ 是浅层 $f_0$，$f(x)$ 是包含它的新函数 $f_1$。
- **根治梯度消失的数学**（必记）：反向传播由**连乘** $\prod_i \partial f_i/\partial f_{i-1}$ 变成**加法 +1**：$\partial f/\partial x=\partial g/\partial x + 1$。即便 $\partial g/\partial x$ 极小，**"+1" 保证梯度无损传回浅层**——告别"大数×小数×小数…"的灾难式衰减。
- **两种残差块**：
  - **恒等块** (`use_1x1conv=False`)：输入输出形状一致，shortcut 直接传 $x$。
  - **卷积块** (`use_1x1conv=True, strides=2`)：当**通道翻倍 / 高宽减半**时，shortcut 用 `Conv1×1` 调形状——**关键：这个 1×1 卷积的 stride 也必须 = 2**，否则两路形状对不上无法相加。
- **ResNet-18 结构**（输入 `1×224×224`）：`stem`(7×7s2+Pool)→ 4 个 stage（每 stage 2 个残差块，**首块下采样**：高宽减半、通道翻倍 $64\to128\to256\to512$）→ GAP → FC(512→10)。层数 = $1 + 2{\times}2{\times}4 + 1 = 18$。
- **实战**：lr=0.05，epochs=10，bs=256，resize=96 → train acc ≈ 0.996 / test ≈ 0.916（**明显过拟合**）。改进：加 `weight_decay=0.005` + `Dropout(0.5)` 缩小 train/test 差距。仍需小心 lr 过大致初期 loss 爆炸。

# 📒 246–263 序列建模：从 RNN 到 Transformer（精简版）

> 一条主线：**怎么建模序列 → 怎么有记忆 → 怎么记得久 → 怎么处理「序列对」 → 怎么打破信息瓶颈 → 怎么彻底抛弃循环**。每章都在补上一章暴露的缺陷。
> 两个贯穿全程的拷问：① **记忆 vs 并行**——既记住远处信息、又能高效并行；② **query / key / value**——后半段所有模型的统一语言（注意各模型里谁当 query、谁当 key/value）。

## 一、序列基础（246–248）：让数据可建模 / 可输入 / 可评价

### 246 序列模型
- **特点**：序列数据**有先后、前后相关**。建模目标 = 给定历史预测下一步，联合概率按时间分解：
  $$p(x_1,\dots,x_T)=\prod_{t=1}^{T}p(x_t\mid x_1,\dots,x_{t-1})$$
  字符定义：$x_t$ 第 $t$ 步观测，$T$ 序列长，$p(x_t\mid\cdots)$ 给定历史的条件概率。这就是 **自回归（autoregressive）**。
- **马尔可夫假设**：只依赖最近 $\tau$ 步 $p(x_t\mid x_{t-\tau},\dots,x_{t-1})$ → 输入定长，**可直接用 MLP**。这是用普通网络硬做序列的起点。

### 247 文本预处理
- **四步流水线**：**读取 → 词元化(tokenize) → 构建词表(Vocab) → 映射成索引**。
- **词表 Vocab**：把每个词元映射到整数 id，并保留**特殊词元**（`<unk>` 未知、后续还有 `<bos>/<eos>/<pad>`）。

### 248 语言模型
- **定义**：估计上面那个 $p(x_1,\dots,x_T)$。早期 **n-gram**（基于计数 + 马尔可夫假设）。
- **困惑度 perplexity（必记评价指标）**：
  $$\mathrm{PPL}=\exp\!\Big(-\frac1n\sum_{t=1}^{n}\log p(x_t\mid x_{t-1},\dots,x_1)\Big)$$
  字符定义：$n$ 总词元数，$p(x_t\mid\cdots)$ 模型给真实下一词的概率。
- **直觉**：PPL = 「平均交叉熵」的指数 = 模型每步在多少个候选词间「纠结」。**PPL=1 完美，PPL=词表大小≈瞎猜，越小越好**。

## 二、循环神经网络（249–254）：给网络装上「记忆」

### 249 / 250 RNN —— 用隐状态承载记忆
- **核心公式**：引入随时间传递的隐状态 $\mathbf H_t$ 压缩历史：
  $$\mathbf H_t=\phi(\mathbf X_t\mathbf W_{xh}+\mathbf H_{t-1}\mathbf W_{hh}+\mathbf b_h),\qquad \mathbf O_t=\mathbf H_t\mathbf W_{hq}+\mathbf b_q$$
  字符定义：$\mathbf X_t$ 当前输入，$\mathbf H_t/\mathbf H_{t-1}$ 当前/上一步隐状态，$\mathbf W_{hh}$ 是「记忆」的载体（让信息沿时间传递），$\phi$ 如 tanh。**所有时间步共享同一套权重**。
- **痛点**：训练用 **BPTT**（沿时间反向传播），梯度连乘 → **梯度消失/爆炸** → 记不住**长程依赖**。这是后面所有改进的起点。
- **训练三件套（一手实现细节）**：
  - **梯度裁剪**治爆炸：`if norm>θ: g *= θ/norm`（θ=1）——**唯一可行**且**保留梯度方向**（只缩模长）。
  - **`state.detach_()` 截断 BPTT**：**顺序采样必须调用**（否则计算图随时间无限增长）；**随机采样**每个 batch 重置隐状态 → 不需要。
  - 监控指标 = 困惑度 `exp(平均交叉熵)`。
- **预测 `predict`**：**预热**阶段把前缀逐字喂入、只更新隐状态不记录；**生成**阶段每步取 `argmax` 作下一步输入（**自回归**）。
- **实战**：Time Machine 数据集，bs=32，num_steps=35，epochs=500，**lr=1**（RNN 容忍大 lr，与后面注意力模型形成鲜明对照）。

### 251 GRU —— 用门控选择性记忆
- **两个门**：重置门 $\mathbf R_t$（要不要忘掉过去）、更新门 $\mathbf Z_t$（用旧状态还是新状态）。候选与更新：
  $$\tilde{\mathbf H}_t=\tanh(\mathbf X_t\mathbf W_{xh}+(\mathbf R_t\odot\mathbf H_{t-1})\mathbf W_{hh}+\mathbf b_h),\qquad \mathbf H_t=\mathbf Z_t\odot\mathbf H_{t-1}+(1-\mathbf Z_t)\odot\tilde{\mathbf H}_t$$
- **核心 4 行代码骨架**：
  ```python
  Z = sigmoid(X@W_xz + H@W_hz + b_z)            # 更新门
  R = sigmoid(X@W_xr + H@W_hr + b_r)            # 重置门
  H_tilda = tanh(X@W_xh + (R*H)@W_hh + b_h)     # 候选状态（R 先作用于旧 H）
  H = Z*H + (1-Z)*H_tilda                       # 凸组合更新
  ```
- **直觉**：$\mathbf Z_t$ 是「混合旋钮」——$\to1$ **保留旧记忆**（梯度抄近路、长期记忆得存），$\to0$ 采纳新信息。
- **三种极端情形**：$Z=1$ 完全保留历史；$Z=0\,\&\,R=1$ 退化为普通 RNN；$R=0$ 忽略历史彻底重置。
- **实现坑**：参数生成函数 `three()` 被调 **3 次**（RNN 只 1 次）；`nn.GRU` 比手写快约 **10×**（内部 fused 优化）。

### 252 LSTM —— 更精细的三门 + 记忆元
- **三门 + 独立记忆元 $\mathbf C_t$**：遗忘门 $\mathbf F_t$、输入门 $\mathbf I_t$、输出门 $\mathbf O_t$：
  $$\mathbf C_t=\mathbf F_t\odot\mathbf C_{t-1}+\mathbf I_t\odot\tilde{\mathbf C}_t,\qquad \mathbf H_t=\mathbf O_t\odot\tanh(\mathbf C_t)$$
  字符定义：$\mathbf C_t$ 记忆元（长期记忆），$\mathbf F_t$ 留多少旧货，$\mathbf I_t$ 写多少新货，$\mathbf O_t$ 从记忆元读多少给隐状态。
- **核心 6 行代码骨架**：
  ```python
  I = sigmoid(X@W_xi + H@W_hi + b_i)            # 输入门
  F = sigmoid(X@W_xf + H@W_hf + b_f)            # 遗忘门
  O = sigmoid(X@W_xo + H@W_ho + b_o)            # 输出门
  C_tilda = tanh(X@W_xc + H@W_hc + b_c)         # 候选记忆
  C = F*C + I*C_tilda                           # 记忆元更新（加法！）
  H = O*tanh(C)                                 # 受控读出
  ```
- **直觉**：$\mathbf C_t$ 是「传送带」——遗忘门擦旧货、输入门放新货，隐状态 $\mathbf H_t$ 再由输出门**按需读取**。读写分离 → 长期信息更稳。
- **三种极端情形**：$F=1\,\&\,I=0$ 记忆原样跨任意步保留；$F=0\,\&\,I=1$ 完全丢弃历史；$O=0$ 记忆隐藏不影响外部预测。
- **LSTM vs GRU（核心易混）**：GRU 记忆与输出**未解耦**、用**凸组合**更新；LSTM 记忆 $\mathbf C_t$ 与输出 $\mathbf H_t$ **解耦**、用**加法**更新 → **梯度流动更稳**（代价：状态是二元 `(H,C)`，`three()` 调 4 次、参数更多）。

### 253 深层 RNN / 254 双向 RNN
- **深层 RNN**：多个 RNN 层**纵向堆叠**，下层输出作上层输入 → 增强表达力（类比 MLP 加深）。
- **双向 RNN**：同跑**前向 + 后向**两个 RNN、拼接隐状态 → 每个位置同时看到**过去和未来**上下文。
- **关键限制（易错）**：双向 RNN **不能做自回归预测**（推理时拿不到未来），**只能用于特征抽取 / 完形填空类任务**。

## 三、序列到序列（255–258）：处理「输入输出都是序列」

### 255 机器翻译数据集
- **序列对任务**（英→法，长度还不等）。预处理要点：小写化、标点加空格、**源/目标各建一个词表**、`<bos>`(句首)/`<eos>`(句尾)/`<pad>`(填充) 特殊词元，每句**截断或填充**到定长，并记录**有效长度 valid_len**（后续掩码要用）。

### 256 编码器-解码器架构
- **通用范式**：**编码器**把输入序列压成中间表示（上下文），**解码器**再从中生成输出序列。是抽象接口，RNN/CNN/Transformer 都能往里套。

### 257 seq2seq —— 用 RNN 实现编码器-解码器
- **结构**：编码器 RNN 读完源句，取**最后隐状态**作上下文向量 $\mathbf c$；解码器 RNN 以 $\mathbf c$ 为初态逐词生成。
  - **context 传递**：`context = state[-1]` 复制到每个解码步，与该步词嵌入**拼接**后输入。
- **teacher forcing（训练技巧）**：`dec_input = cat([<bos>, Y[:,:-1]])`——每步喂**真实的上一个词**（非模型预测）。优点收敛快稳，缺点训练/推理不一致的**曝光偏差**。
- **掩码处理变长（一手细节）**：
  - `sequence_mask`：把超出 valid_len 的位置置 0；
  - `MaskedSoftmaxCELoss`：填充位**权重置 0**，只对真实词元求 loss（填充不污染梯度）。
- **BLEU 评价（必记）**：
  $$\mathrm{BLEU}=\exp\!\Big(\min\big(0,\,1-\tfrac{\mathrm{len}_{\text{label}}}{\mathrm{len}_{\text{pred}}}\big)\Big)\prod_{n=1}^{k}p_n^{\,1/2^n}$$
  字符定义：$p_n$ 是 $n$-gram 匹配精度，$k$ 最大阶数。前项=**短句惩罚**（译文太短扣分），后项=各阶 n-gram 精度乘积且**长匹配权重更大**。∈[0,1]，越接近 1 越好。
- **暴露的痛点**：整句被压成**一个固定向量 $\mathbf c$**，长句装不下 → **信息瓶颈**（注意力就是来解决它的）。
- **实战**：bs=64，num_steps=10，**lr=0.005，epochs=300**（lr 比 RNN 小约 200×）；小词表 embed=8/hidden=16/2 层，仅 600 个翻译对。

### 258 束搜索 —— 推理阶段怎么搜
- **背景**：训练有真实标签、推理没有，必须逐词搜索最优序列。三策略同一谱系：

  | 束宽 $k$ | 方法 | 特点 |
  |---|---|---|
  | $k=1$ | 贪心搜索 | 每步取最大概率，最快但易陷局部最优 |
  | $1<k<n$ | **束搜索** | 每步保留最好的 $k$ 个候选，质量/算力平衡 |
  | $k=n$ | 穷举搜索 | 最优但 $n^T$ 不可行 |

- **长度归一化**：最终评分 $\frac{1}{L^\alpha}\sum\log p$（$\alpha\approx0.75$），抵消「短句 log 概率天然更大」的偏好，避免输出过短。

## 四、注意力 → Transformer（259–263）：抛弃循环，走向并行

### 259 注意力机制 —— query / key / value 的诞生
- **统一写法**：
  $$f(x)=\sum_i \alpha(x,x_i)\,y_i$$
  字符定义：$x$ 是 query，$x_i$ 是 key，$y_i$ 是 value，$\alpha(x,x_i)$ 是注意力权重（和为 1）。
- **直觉**：输出 = 对所有 value 的**加权平均**，权重由「query 与 key 的匹配度」决定。**不同注意力的区别全在 $\alpha$ 的设计**。Nadaraya-Watson 核回归是它最早的非参实例。

### 260 注意力分数 —— 权重到底怎么算
- **权重 = 对分数 $a(\mathbf q,\mathbf k)$ 做 softmax**。两种主流分数函数：
  $$\text{加性：}\;a=\mathbf w_v^\top\tanh(\mathbf W_q\mathbf q+\mathbf W_k\mathbf k)\qquad\qquad\text{缩放点积：}\;a=\frac{\mathbf q^\top\mathbf k}{\sqrt d}$$
- **加性 vs 缩放点积（核心易混）**：
  - **加性** `AdditiveAttention`（`W_q/W_k/w_v`）：小 MLP 打分，**q/k 维度可不同**，但慢。
  - **缩放点积** `DotProductAttention`（`bmm(q,kᵀ)/√d`）：**无参数**、纯矩阵乘、最快，但 **q/k 维度须相同**。Transformer 选它。
- **为什么除 $\sqrt d$**：高维点积方差随 $d$ 增大 → softmax 进饱和区**梯度消失**；除 $\sqrt d$ **控制方差**。
- **masked softmax（一手细节）**：把无效（填充）位分数设为 **−1e6** → `exp` 后≈0、权重≈0，处理变长序列的标准做法。

### 261 Bahdanau 注意力 —— 打破固定上下文瓶颈
- **核心改动**：不再用固定 $\mathbf c$，而是**每个解码步动态算一个上下文**：
  $$\mathbf c_{t'}=\sum_{t=1}^{T}\alpha(\mathbf s_{t'-1},\mathbf h_t)\,\mathbf h_t$$
  字符定义：$\mathbf s_{t'-1}$ 解码器上一步隐状态（= **query**），$\mathbf h_t$ 编码器各步输出（= **key 和 value**）。
- **直觉**：解码每个词时，用「我下一步想译什么」(query) 去源句里**动态挑选**该关注的部分。这是 **query 与 key/value 不同源**的**交叉注意力（cross-attention）**。

### 262 自注意力 —— 序列自己看自己
- **定义**：序列里每个元素**同时当 query/key/value**（**q 与 k/v 同源** = self-attention）：$\mathbf y_i=f(\mathbf x_i,(\mathbf x_1,\mathbf x_1),\dots,(\mathbf x_n,\mathbf x_n))$。
- **三模型复杂度对比（必记）**：

  | 指标 | CNN | RNN | 自注意力 |
  |---|---|---|---|
  | 计算复杂度 | $O(knd^2)$ | $O(nd^2)$ | $O(n^2d)$ |
  | 并行度 | $O(n)$ | $O(1)$ ❌ | $O(n)$ ✅ |
  | 最长路径 | $O(n/k)$ | $O(n)$ ❌ | $O(1)$ ✅ |

- **核心结论**：自注意力 = **完全并行 + 任意两词一步直达**（长依赖友好），代价是 $O(n^2)$ 平方复杂度。**这就是它取代 RNN 的根本原因**。
- **位置编码**：自注意力本身不感知顺序，用 sin/cos 矩阵加到输入：$p_{i,2j}=\sin(i/10000^{2j/d})$，$p_{i,2j+1}=\cos(\cdots)$。同时编码**绝对位置**（唯一指纹，类比二进制）与**相对位置**（$i{+}\delta$ 可由 $i$ 经与 $i$ 无关的旋转矩阵线性得到）。

### 263 Transformer —— 纯注意力的集大成
- **整体**：纯注意力的编码器-解码器（**无 RNN/CNN**）。每块 = 多头(自)注意力 + 基于位置 FFN + 残差&层归一化。
- **多头注意力**：$h$ 个独立子空间各投影各算一次注意力（学短/长距离等不同关系），拼接经 $\mathbf W_o$ 融合：
  $$\mathbf h_i=f(\mathbf W_i^{(q)}\mathbf q,\mathbf W_i^{(k)}\mathbf k,\mathbf W_i^{(v)}\mathbf v),\qquad \text{输出}=\mathbf W_o[\mathbf h_1;\dots;\mathbf h_h]$$
- **三种注意力分工（务必记牢）**：

  | 位置 | 类型 | query 来源 | key/value 来源 |
  |---|---|---|---|
  | 编码器 | 自注意力 | 源序列 | 源序列 |
  | 解码器第 1 层 | **带掩码**自注意力 | 目标序列(已生成) | 目标序列(已生成) |
  | 解码器第 2 层 | 编码器-解码器注意力 | 目标序列 | **编码器输出** |

- **带掩码**：解码自回归，预测第 $i$ 词只能看前 $i$ 个 → 用 `dec_valid_lens=arange(1,T+1)` 构成**下三角**屏蔽未来（保证因果性）。
- **基于位置 FFN**（`PositionWiseFFN`）：对**每个位置独立**做两层 MLP（位置间不交互），等价两层 1×1 卷积，逐位置加深非线性。
- **Add&Norm**（`ln(dropout(Y)+X)`）：**用层归一化 LayerNorm 而非 BatchNorm**——NLP 序列变长、batch 维统计量不稳；LayerNorm 对每个样本自身归一化 → 配残差支撑深层堆叠。
- **结构约束**：编码器输出当解码器 cross-attn 的 K/V，解码器序列当 Q → **编/解码器块数与输出维度须一致**。
- **实战**：num_hiddens=32，num_layers=2，dropout=0.1，bs=64，num_steps=10，**lr=0.005，epochs=200**（比 seq2seq 的 300 轮还少，注意力收敛更快）。

## 五、把整条主线连起来

### 一句话演进史
```
序列怎么建模？        → 自回归 / 语言模型        (246-248)
怎么有记忆？          → RNN 隐状态               (249-250)
记不住长程怎么办？     → GRU / LSTM 门控          (251-252)
表达力/上下文不够？    → 深层 / 双向 RNN          (253-254)
输入输出都是序列？     → 编码器-解码器 / seq2seq   (255-257)
推理怎么搜好句子？     → 束搜索                   (258)
固定上下文向量瓶颈？   → 注意力 / Bahdanau        (259-261)
循环太慢、长依赖难？   → 自注意力 + 位置编码       (262)
干脆不要循环？        → Transformer             (263)
```

| 门控（GRU/LSTM） | RNN 梯度消失、长依赖 | 251-252 |
